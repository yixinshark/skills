# 价值投资研究技能 - SKILL.md (v2)

## 价值投资研究技能

### 核心原则

投资三要素（按优先级）：

1. **好生意** — 商业模式简单、护城河深、能长期存续
2. **好文化** — 管理层诚信、股东导向、资本配置能力强
3. **好价格** — 足够安全边际

> 段永平：先想清楚这是不是一门好生意、一家好公司，再谈价格。价格错了最多亏钱，方向错了则全军覆没。

---

## 研究流程

### 步骤0：能力圈自检（最优先，先于一切）

在开始任何研究之前，必须回答：

- **我是否真正理解这家公司的生意是怎么赚钱的？**
- 我能用一两句话向外行说清楚它的商业模式吗？
- 我对这个行业有没有第一手的认知（使用过产品、了解行业逻辑）？
- 如果不能满足以上条件 → **放弃，换下一个**，不在能力圈内的机会不是机会

> 巴菲特：我宁愿在能力圈内做简单的判断，也不愿在圈外做复杂的分析。能力圈的大小不重要，清楚边界在哪里才重要。

---

### 第一步：垃圾企业过滤（一票否决）

任何一条命中即判定为「不碰」，终止研究并告知用户原因：

- ROE连续3年 < 10%（非周期行业）
- 经营现金流/净利润连续3年 < 0.7（利润质量差）
- 资产负债率 > 70%（非金融企业）
- 商誉/净资产 > 30%（并购依赖）
- 管理层近1年大额净减持（⚠️ 需先核实减持原因：若为离婚、缴税、个人资产配置等与经营无关原因，可不否决；若无合理解释则否决）
- **重资产且利润微薄（"碎钞机"生意）**：资本开支常年远超折旧摊销，且ROIC低下，需频繁外部借款/融资才能维持生存的企业
- 频繁再融资稀释股东
- 主业不清晰、频繁跨界
- 企业或管理层有违法行为、行政处罚、证监会处分记录
- 管理层诚信存疑（财务造假、虚假陈述、内幕交易等前科）
- **财务造假高危信号**（新增）：
  - 存贷双高（账上大量现金却同时高额借债）
  - 10年累计经营现金流/累计净利润 < 0.6
  - 应收账款增速连续2年远超营收增速
  - 审计报告非标准无保留意见

> **过滤结果输出标准**：
> - **✅ 通过初筛**：未触碰任何红线，进入深度研究。
> - **❌ 一票否决（不碰）**：当触碰红线时，需提供结构化的深度否决原因，包含：
>   1. **否决事件描述**：[具体时间节点] 发生了 [什么具体事实]。
>   2. **核心动机推测**：透过现象看本质，管理层这一动作背后的真实利益考量是什么？（例如：收益私有化、风险公众化、掩盖利润下滑等）。
>   3. **触碰的价投底线**：明确指出违背了哪一条大师原则（例如：违背段永平的"本分与诚信"最高红线、触碰巴菲特厌恶的"碎钞机模式"等）。

### 第二步：商业模式与行业竞争格局

#### 企业历史关键节点

> 唐朝：一家企业的历史，就是管理层决策质量的完整考试卷。
> 段永平：要看这家公司过去10-20年做了什么"对的事情"和"不对的事情"。

**需要梳理的关键节点类型**：
1. **创立与早期定位**：创始人背景、初始商业模式、早期核心竞争力从何而来
2. **关键战略转折**：重大业务方向调整（成功/失败的转型）
3. **重大并购/剥离**：花大钱买了什么？卖掉了什么？事后看是好买卖还是烂买卖？
4. **危机应对**：遇到行业寒冬/重大事故/政策打击时，管理层如何反应？是壮士断腕还是掩耳盗铃？
5. **上市/融资/分红节点**：什么时候融了多少钱？用来干了什么？对股东是利还是弊？
6. **管理层交接**：创始人何时交棒？继任者是谁？交接是否平稳？

**从历史中提炼的"企业基因"判断**：
- 这家公司的基因是"进攻型"还是"防守型"？
- 历史上遇到诱惑时选择了克制还是贪婪？
- 核心竞争力的形成是靠运气（时代红利）还是靠实力（持续正确的决策）？


#### 业务深度白描（必须完成）

> 唐朝：如果你的研究笔记给一个完全不懂行的朋友看，他读完仍然搞不清楚这家公司到底是干嘛的，那你还没真正搞懂。
> 段永平：好的生意应该是你能用常识去理解的。

**对每条主要业务线，必须用叙述文字回答以下问题**：

1. **产品/服务的实物描述**：
   - 产品长什么样？能不能举一个消费者日常接触到的实例？
   - （例：永新的彩印复合膜 → 就是你在超市拿到的伊利牛奶外面那层印着品牌logo的塑料包装袋，摸起来有多层质感，能阻隔氧气保持牛奶新鲜）

2. **一笔生意从头到尾的流程**：
   - 客户怎么找上门的？（招标/长期合约/认证入围）
   - 从接到订单到交付产品经历了哪些步骤？
   - 回款周期多长？账期是什么条件？

3. **客户为什么选这家公司而不是竞争对手？**：
   - 是因为便宜？品质？服务响应速度？认证门槛已经过了不想重来？
   - 客户的真实决策逻辑是什么？

4. **一个典型客户的生命周期价值（LTV思维）**：
   - 客户一旦进来，平均合作几年？
   - 每年采购量是稳定/增长/波动的？
   - 客户流失率大约多少？

5. **这个生意日常运转中最关键的"命门"是什么？**：
   - 什么环节一旦出问题，整个生意就转不动了？

6. **这个生意的"节奏感"**：
   - 有没有明显的淡旺季？
   - 收入是一次性的还是持续复购的？
   - 回头客占比大约多少？

#### 四大核心问题验证（看懂一家企业的钥匙）

> 唐朝：当你能够清晰回答以下四个问题时，就代表基本看懂了这家企业。回答不清楚，就不要急着估值。

**问题一：这家公司靠销售什么商品和服务获取利润？**
- 要具体到：卖什么产品/服务 → 卖给谁 → 怎么收费 → 利润率多高
- **回答**：[必须用2-3句大白话写清楚]

**问题二：客户为何选它而不选竞争对手？**
- 客户的真实决策逻辑是什么？（便宜？品质？锁定效应？品牌信任？认证门槛？）
- **回答**：[必须用大白话写清楚]

**问题三：为什么其他资本没来抢它的市场？**

> 唐朝：资本的天性是逐利。长期赚取超额利润，一定有力量在阻止他人进入。找到这个力量。

- 识别1-3个核心护城河（品牌/成本/网络效应/转换成本/牌照/技术），用实例说明
- **回答**：[必须识别核心护城河并用实例说明]

**问题四：巨头挟巨资参与竞争，能否保住份额？**
- 护城河"坚固程度"的终极测试：历史上有没有巨头尝试进入失败的案例？
- **回答**：[必须给出明确判断，附理由]

**四大问题总评**：全部清晰→可进入估值 / 部分模糊→继续研究 / 答不清→建议放弃

#### 业务结构拆解（必须量化，从年报中提取）

- **各业务线收入构成**（表格形式，附毛利率）：明确每条产品线的营收、占比、毛利率，识别利润核心业务
- **收入地域结构**：国内 vs 海外占比；海外毛利率是否优于国内，海外布局方向
- **怎么赚钱的底层逻辑**：成本结构（原材料占比）、定价方式、规模效应的体现方式

#### 上下游结构（量化，从年报中提取）

**下游客户**：
- 已知核心客户名称（公开披露部分）
- 前五大客户销售额及合计占比（年报披露）
- 客户集中度判断：<25% 分散（低风险）；25-50% 中等；>50% 集中（高风险）
- 客户行业分布（食品/日化/医药等各自占比）

**上游供应商**：
- 主要原材料种类及价格敏感性（是否与大宗商品/油价挂钩）
- 前五大供应商采购额及合计占比（年报披露）
- 供应商集中度判断：<30% 分散；30-50% 中等；>50% 存在供应风险
- 公司是否在推进自建产业链以降低外采依赖

#### 行业竞争格局（必须分析）

- 行业整体规模、增速、天花板（市场空间有多大）
- **行业价值链结构**：上游→中游→下游各方的议价能力与利润分配
- **行业周期性**：是强周期/弱周期/非周期？利润率主要受什么变量驱动？最佳买入时机判断
- 竞争状态：完全竞争 / 寡头垄断 / 垄断；CR3/CR5 集中度
- 主要竞争对手列表：名称、营收规模、市占率、核心优势
- 目标公司在行业中的排名和市占率；5年增速 vs 竞争对手对比
- 行业进入壁垒高低（认证/资本/技术/品牌各维度）
- **政策与监管风险**：行业相关重大政策方向，是否存在技术升级/替代材料/环保合规等长期威胁
- 波特五力综合评分（附对目标公司具体影响说明）

#### 定价权评估（巴菲特通胀测试）

> 核心问题：**如果这家公司明天提价10%，客户会跑吗？**

- 历史上有无提价记录？提价后销量如何变化？
- 客户对价格的敏感度（刚需 vs 可选消费）
- 是否存在替代品压制定价空间？
- **结论**：定价权强 / 有限 / 无（附理由）

#### 护城河评估（每项1-5星 + 动态趋势）

| 维度 | 当前评分（1-5星） | 趋势（↑扩大/→稳定/↓收窄） |
|---|---|---|
| 客户转换成本 | | |
| 规模/成本优势 | | |
| 品牌/信誉 | | |
| 技术/专利壁垒 | | |
| 网络效应 | | |
| 特许经营权/牌照 | | |
| **企业文化（隐形护城河）** | | |

- **护城河总评：** 强 / 中等 / 弱（附理由）
- **商业模式的资本属性验证（印钞机 vs 碎钞机）**：业务增长是否需要成比例的庞大资本投入？维持现有利润的资本开支占多大？（好的生意是做大了就不需要怎么再投大钱的）。
- **动态判断：** 与3-5年前相比，护城河是在扩大还是收窄？竞争对手是否在蚕食份额？行业技术变革是否构成威胁？

#### 行业生命周期与演化趋势（时光机/参照系推演）

> 核心思想：**处于早中期的新兴市场/行业，通常会重演成熟市场/行业的历史路径。** （即孙正义的"时光机理论"）

- **当前所处阶段**：导入期 / 爆发期（量增为主） / 成熟期（存量博弈、集中度提升） / 衰退期（判断依据是什么？）
- **成熟市场参照系**：欧美、日本或中国一二线城市在类似发展阶段时，行业发生了什么关键变化？
- **演化推演**：未来3-5年，行业竞争的**核心驱动力**将从什么变成什么？（例如：从"渠道下沉"到"产品细分"，从"低价格战"到"品牌溢价"）
- **公司适配度研判**：目标公司当前的竞争优势，在进入下一个行业发展阶段时，是会失效还是依然适用？公司是否有能力完成战略跨越？

#### 10年后的公司图景（段永平灵魂问题）

> 段永平：我买公司之前一定要想清楚，10年后这家公司还在做同样的生意吗？

- 10年后这个行业还存在吗？需求是否会因技术/消费习惯变化而消失？
- 10年后这家公司的竞争地位是更强还是更弱？
- 当前的护城河能维持10年吗？
- **结论**：长期存续的确定性 高 / 中 / 低

### 第三步：企业文化评估

#### 管理层团队与变更历史

> 段永平：我投的是人，不是股票。对的人做什么都能做好。
> 巴菲特：我要找的是已经很优秀、不需要我管理的管理者。

**核心管理层档案**（列表形式）：
- 姓名、职位、任期、背景/履历、持股比例、核心评价

**管理层变更时间线**（如有重大变更需记录）：
- 时间、变更事件、原因、对公司影响

**需要回答的关键问题**：
- 现任CEO/董事长是创始人还是职业经理人？这对公司文化有何影响？
- 有没有发生过不正常的管理层集体离职/被解职事件？
- 核心管理团队的稳定性如何？（高管平均任期）
- 继任计划是否清晰？如果现任CEO明天退休，公司能否平稳过渡？

#### 管理层能力与品格深度评估——"听其言、观其行"

> 唐朝：年报中管理层的话，值得逐字逐句研读。把今年说的和去年做的对照看，一个人的品格就出来了。
> 段永平：说一套做一套的管理层，给再便宜的价格都不能碰。

**一、"言行一致性"审计（至少追溯3年年报/业绩说明会）**

| 年份 | 管理层当年说了什么（承诺/目标/战略表态） | 次年实际结果如何 | 一致性评分（✅兑现/🟡部分兑现/❌落空） |
|---|---|---|---|

**言行一致性总评**：高度一致 / 基本一致 / 严重不一致（附说明）

**二、面对困难时的态度（逆境见真章）**

> 段永平：一家公司好不好，不是看顺风顺水时说什么，而是看逆风逆水时做什么。

- **公司最近一次重大困难/危机是什么？**（营收下滑/行业寒冬/政策打击/产品事故等）
- **管理层当时怎么说的？**（是坦诚承认问题还是粉饰太平？是主动担责还是甩锅外因？）
- **管理层当时怎么做的？**（裁员？收缩？加码？死扛？）
- **事后回看，管理层的应对是否正确？**

**三、诚恳度评估（年报/业绩说明会"话术"分析）**

> 唐朝：好的管理层会在年报里主动讲"我们做得不好的地方"。差的管理层只会歌功颂德、报喜不报忧。

- **年报中是否主动披露负面信息？**（例如竞争加剧、增速放缓、失误复盘）
- **是否使用大量模糊/回避性语言？**（如"进一步加强"、"持续推进"等无实质内容的官话）
- **是否有具体的数字目标和自我约束？**（而非空洞的愿景口号）
- **对分析师/投资者提问的回应质量如何？**（是正面回答还是顾左右而言他？）

**管理层话语的关键摘录**（原文引用，正面+负面各至少一条）：

| 出处（年报/电话会/采访） | 原文引用 | 分析评价 |
|---|---|---|

**四、管理层格局与视野**

> 巴菲特：好的管理者像是公司的owner（主人），而不是employee（打工人）。

- **管理层是否有"主人翁"思维？**（是在为公司百年计还是只看任期内KPI？）
- **对待竞争对手的态度**：是尊重对手、专注自身（本分），还是攻击对手、盲目自信？
- **对待行业趋势的判断**：是否有远见？还是随波逐流？
- **段永平"本分"测试**：管理层在面对"做对的事 vs 赚快钱"的冲突时，历史上选了哪边？

|---|---|---|

#### 本分与诚信（最深的护城河）

> 段永平：企业文化本身就是最深的护城河。如果文化不对，其他护城河迟早被填平。

- **本分与短期利润的取舍**：当"做对的事情"与"赚短期利润"冲突时，管理层如何选择？公司是否真正在为用户创造价值（而非单纯利用人性弱点）？
- 管理层言行一致性（对比历年致辞与实际经营）
- 管理层诚信 — 有无违法违规、行政处罚、证监会处分、诉讼纠纷
- 企业合规记录 — 有无环保处罚、税务问题、产品质量事故
- 信息披露质量（是否主动、透明、一致）

#### 股东导向

- 分红历史（是否持续、慷慨）
- 股权激励是否合理（行权条件是否真正高要求）
- 关联交易是否频繁

#### 管理层资本配置能力（巴菲特首要标准）

> 巴菲特：一家公司的命运，很大程度上取决于管理层如何分配资本。这是CEO最重要的能力，但商学院几乎不教。

- **历史收购记录**：做过哪些并购？是否创造了价值，还是溢价买入烂资产？
- **股份回购时机**：是否在低估时回购，高估时不买？
- **资本开支纪律**：高增长期是否克制，没有盲目扩张？
- **留存利润效率**：留下来的每1元利润，最终产生了多少市值？
- **资金去向透明度**：管理层对"钱花在哪里"是否解释清楚？
- **结论**：资本配置能力 优秀 / 一般 / 差（附例证）

**（二）增长曲线形状分析**

> 关键不是某一年的数字，而是增长曲线的"形状"。不同形状代表完全不同的企业生命阶段和投资价值。

**营收增长曲线类型判断**（必须明确标注）：
- [ ] 📈 持续上升型（年化 > 10%，如快手）
- [ ] 📊 稳健增长型（年化 5-10%，如永新股份）
- [ ] ➡️ 平台期/横盘型（年化 0-5%，增长乏力）
- [ ] 📉 衰退型（营收持续下滑）
- [ ] 🎢 强周期波动型（大起大落，跟随行业周期）
- [ ] 🏒 J型/Hockey Stick型（前期亏损积累，某一年突然爆发）

**利润增长曲线 vs 营收增长曲线的对比**：
- 利润增速 > 营收增速？→ 经营杠杆在释放（好信号）
- 利润增速 < 营收增速？→ 竞争在加剧/成本在膨胀（坏信号）
- 利润增速与营收增速长期同步？→ 商业模式稳定

|---|---|---|---|

#### 核心指标（近5年详细分析）

- 营收、净利润及增速
- **ROE**（杜邦分解：利润率 × 周转率 × 杠杆）
- **ROIC**（投入资本回报率，剔除杠杆影响，更真实反映生意本质）
  - ROIC = NOPAT / 投入资本（有息负债 + 净资产）
  - 若 ROIC 持续 > 15%，说明是真正的好生意
  - 同时看含商誉和剔除商誉两个口径
- **再投资能力**：再投资率 = 净增资本开支 / NOPAT；趋势是否递减？
- 毛利率、净利率
- 经营现金流/净利润
- 自由现金流 = 经营现金流 - 资本开支
- **资本密集度（Capex / 折旧与摊销）**：长期 < 1 是极佳的轻资产印钞机；远 > 1 则说明在流血维持运转。
- 资产负债率
- 分红率、股息率


#### 利润含金量检验——"赚到的是真钱还是假钱"

> 唐朝：净利润是意见，现金流是事实。一家连续多年利润高增长但现金流跟不上的公司，不是在赚钱，是在编故事。

**（一）核心验证指标**

| 检验项 | 计算方式 | 健康标准 | 危险信号 |
|---|---|---|---|
| **经营现金流/净利润** | OCF / Net Income | 长期 >= 0.8，最好 > 1.0 | 连续2年 < 0.7 |
| **累计比较法（唐朝法）** | 近5-10年累计OCF / 近5-10年累计净利 | >= 0.8 | < 0.7 说明利润长期"注水" |
| **净现比（单年波动可接受，但趋势不能恶化）** | 逐年列示 | 均值 > 0.85 | 逐年下降趋势 |
| **自由现金流是否为正** | FCF = OCF - Capex | 长期为正 | 连续3年为负 |
| **分红来源验证** | 分红是用经营现金流支付，还是靠借债/融资支付？ | 分红 <= FCF | 分红 > FCF（寅吃卯粮） |

**（二）"钱去哪了"追踪（利润没变成现金的四大去向）**

> 如果公司报了5亿利润，但经营现金流只有2亿，那3亿去哪了？必须逐项追查，看是合理的经营需要，还是危险的利润虚增信号。

| 利润"消失"的去向 | 如何查看 | 合理情况 | 危险情况 |
|---|---|---|---|
| **应收账款膨胀** | 应收增速 vs 营收增速 | 应收增速 <= 营收增速 | 应收增速远超营收（客户赊账越来越多，或虚构收入） |
| **存货积压** | 存货增速 vs 营收增速；存货周转天数 | 存货增速 <= 营收增速 | 存货大幅增长但营收没涨（产品卖不动或刻意囤货做利润） |
| **预付账款异常** | 预付款占营收比例 | < 5% | 大额预付给关联方（可能是变相转移资金） |
| **资本化操作** | 研发/利息/费用资本化比例 | 行业惯例范围内 | 大量本应计入费用的支出被资本化（美化利润） |

**（三）应收账款深度体检**

| 检查项 | 健康标准 | 警报线 |
|---|---|---|
| 应收账款周转天数趋势 | 稳定或缩短 | 连续2年延长 |
| 应收账款占营收比例 | < 25%（制造业）；< 15%（消费品） | 占比逐年攀升 |
| 应收账款账龄结构 | 1年以内占比 > 85% | 1年以上占比快速增加 |
| 坏账计提比例 | 与同行一致或更保守 | 明显低于同行（少提坏账美化利润） |
| 前五大应收客户 | 分散，无关联方 | 大额应收来自关联方或不知名客户 |

**（四）唐朝式"累计法"验证（最简洁有力的一招）**

> 唐朝：不要只看单年的净现比，要看累计。把过去10年的经营现金流加在一起，除以10年的净利润加在一起。如果这个比值低于0.8，这家公司大概率在"赚假钱"。

计算公式：
- 10年累计经营现金流 / 10年累计净利润
- >= 1.0：优秀，赚到的每一分钱都是真金白银
- 0.8 - 1.0：良好，利润含金量可接受
- 0.6 - 0.8：较差，需要深入排查原因
- < 0.6：极差，高度怀疑利润质量，建议放弃

**（五）利润含金量总评**

- 优秀（印钞机）：累计净现比 > 1.0，自由现金流充裕，分红全部由经营现金流覆盖
- 良好（正常企业）：累计净现比 0.8-1.0，偶有单年波动但趋势健康
- 一般（需警惕）：累计净现比 0.6-0.8，利润有一定"水分"
- 差（远离）：累计净现比 < 0.6，利润基本是纸面富贵


#### 盈利质量"三大前提"验证（进入估值的必过关卡）

> 唐朝：只有同时满足三大前提的企业，其报表净利润才能近似替代自由现金流，才有资格用简便方法估值。不满足的企业，要么用更复杂的模型，要么直接放弃。

**前提一：企业赚的是真钱吗？**
- 利润是否有充足的经营性现金流支撑？
- 还是主要由应收账款、资产处置、公允价值变动等"纸面利润"构成？
- 验证方法：累计净现比 >= 0.8（参见上方"利润含金量检验"）。
- **结论**：✅ 赚的是真金白银 / ❌ 利润有水分

**前提二：利润可持续吗？**
- 当前的盈利能力在未来能否持续？而不是：
  - 一次性资产处置收益撑起来的高利润
  - 政策红利/补贴推高的利润
  - 行业景气周期顶部的超额利润
  - 大客户一次性大单带来的脉冲式收入
- 用什么方法判断可持续性：
  - 过去5-10年净利润的波动系数（CV = 标准差/均值），CV < 0.3为稳定
  - 扣非净利润 vs 归母净利润的差距是否长期过大
  - 非经常性损益占净利润比例是否超过20%
- **结论**：✅ 利润可持续 / ⚠️ 有周期波动但可预测 / ❌ 利润不可持续

**前提三：维持当前盈利水平是否需要大量资本投入？**
- 这是一台"现金奶牛"，还是一台需要不断喂食才能运转的"碎钞机"？
- 验证维度：
  - 维持性资本开支 / 折旧摊销的比值（理想 <= 1.2）
  - 自由现金流 / 净利润的比值（理想 > 0.6）
  - 企业是否需要频繁增发/借债才能维持现有规模？
- **结论**：✅ 轻资产/现金奶牛 / ⚠️ 中等资本需求 / ❌ 重资产碎钞机

**三大前提总评**：
- 三项全部 ✅：可以用净利润近似替代自由现金流进行估值，进入估值环节
- 有 ⚠️：需调整估值模型，标注不确定性
- 有 ❌：不适用简便估值法，需用更保守的DCF或直接放弃

> 唐朝：经验丰富的投资者首先聚焦资产负债表，通过简化资产负债表快速把握企业特征。

#### 关注异常信号

- 营收增长但现金流不增长 → 应收账款问题
- 毛利率大幅波动 → 定价能力弱
- 存货周转变慢 → 产品滞销
- 有息负债突增 → 资金链风险
- ROIC 逐年下降但 ROE 稳定 → 依赖加杠杆维持表面回报
- **存贷双高** → 账上大量现金却同时高额借债（财务造假高危信号）
- **营业收入现金含量下降** → 赊销比例提高、收入质量恶化
- **少数股东权益利润率异常** → 可能通过少数股东权益操纵利润分配

### 第五步：估值与买入价

#### 方法一：老唐估值法（满足三大前提后的首选）

> 唐朝：估值就是个毛估估的过程，不要追求精确到分。模糊的正确远胜于精确的错误。
> 巴菲特：宁要模糊的正确，不要精确的错误。

**适用前提（三大前提必须同时满足）**：
1. ✅ 企业赚的是真钱（利润含金量高）
2. ✅ 利润可持续（非一次性/周期性暴利）
3. ✅ 维持盈利不需要大量资本投入（轻资产/现金奶牛型）

**老唐估值法操作步骤**：

**第一步：估算未来第三年的净利润（核心变量）**

> 唐朝：我只估未来三年的利润。再远的事情谁也看不清，不要自欺欺人。

- 基于对企业商业模式、竞争格局、增长驱动力的理解，合理估算目标企业第三年（即当前年份+3年）的归母净利润
- 估算方法（可多种方法交叉验证）：
  - 历史增速外推法（适合增速稳定的企业）
  - 业务拆分法（各业务线分别预估，汇总）
  - 行业空间 × 市占率法（适合成长型企业）
  - 管理层指引 × 打折（对管理层目标打个7-8折）
- **乐观估计**：___亿元（假设条件：___）
- **中性估计**：___亿元（假设条件：___）
- **保守估计**：___亿元（假设条件：___）
- **采用估计值**：___亿元（通常取中性偏保守）

**第二步：确定合理市盈率（PE）**

> 唐朝：合理市盈率的选取，本质上是对企业"确定性"的定价。确定性越高，给的PE越高。

- 合理PE的确定依据：
  - 无风险收益率的倒数作为锚（例：无风险利率3% → 合理PE上限约33倍）
  - 企业增速预期（高增长可给较高PE，但一般不超过25-30倍）
  - 企业商业模式的确定性（护城河越深、利润越稳定，PE越有资格给高）
  - 同行业可比公司的PE区间参考
- **唐朝常用的PE范围**：
  - 优秀且确定性极高的企业：25-30倍PE
  - 稳健增长型企业：15-25倍PE
  - 增长平淡、确定性一般的企业：10-15倍PE
- **本次选用的合理PE**：___倍（理由：___）

**第三步：计算合理估值与买入价**

- **三年后合理市值** = 第三年预估净利润 × 合理PE = ___亿元
- **当前合理价值（折现）** = 三年后合理市值 / (1 + 折现率)^3
  - 折现率通常取全市场期望回报率（唐朝常用约年化15%左右的隐含折现）
  - 简化处理：三年后合理市值 × 0.65（约等于按15%折现3年）
- **合理买入价** = 当前合理价值（折现后）对应的每股价格
- **理想买入价（打7折）** = 合理买入价 × 70%（留足安全边际）

> 唐朝：当前股价 ≤ 合理估值的7折时买入，≥ 合理估值的1.5倍时卖出。中间不动。

- 我对这个行业/公司的认知，有没有已知的盲区？

#### 5年亏损假设

- 如果5年后这笔投资亏了50%，最可能的原因是什么？

#### 偏见检查

> 芒格：人类心理学中有25种标准的错误判断倾向，它们时常组合在一起发挥作用。

- **可得性偏误**：我是否因为最近看到了很多正面信息而高估？
- **确认偏误**：我是否只在搜集支持我买入论点的证据？
- **锚定偏误**：我是否因为某个"目标价"或"内在价值"而不愿修正判断？
- **禀赋效应**：如果我还没持有这家公司，以当前价格，我愿意买入吗？
- **权威偏误**：我是否因为某位大V/基金经理推荐而高估了信心？

#### 辨别真假风险

> 唐朝：市场上充斥着各种"恐慌"，你要分清真风险和假风险。真风险会实质性地、永久性地降低企业内在价值；假风险只会短期影响股价，反而是绝佳的买入机会。

- **识别假风险**（市场恐慌 ≠ 企业受损）：
  - 整体大盘暴跌导致的"陪跌"
  - 短期宏观政策变化带来的情绪冲击
  - 行业负面新闻（别家出事但投资者恐慌性抛售全行业）
  - 一次性罚款/短期业绩不达预期
- **识别真风险**（需要重新评估投资论点）：
  - 核心技术/产品被替代的可能性
  - 管理层诚信出现根本性问题
  - 行业需求结构性萎缩
  - 竞争格局发生根本性变化（强大新对手入场）
  - 监管政策导致商业模式不可持续

#### 鲁拉帕路萨效应（Lollapalooza Effect）检查

- **多维共振**：这家公司是否在多层面上具备优势的同向叠加？（例如：极佳的商业模式 + 狂热的消费者行为 + 极度克制本分的管理层 + 行业正处于爆发期）。如果存在，通常预示着极为恐怖的长期回报。
- 是否存在？描述具体的共振维度：

> 以上问题能清晰回答，且风险可接受 → 继续；无法回答 → 暂停研究，补充信息

### 第七步：生成跟踪清单

为通过研究的企业生成季度/年度跟踪要点：

#### 关键财务指标跟踪

- 重点盯 ROIC、自由现金流、毛利率、净现比
- 应收账款增速 vs 营收增速对比
- 资本开支 vs 折旧摊销对比

#### 经营层面跟踪

- 管理层的承诺兑现度（对照上年的"言"与今年的"行"）
- 核心客户的续约/流失情况
- 新业务/新市场的进展
- 竞争对手的动态

#### 护城河信号监控

- **扩大信号**：市占率提升、定价权增强、客户转换成本增加、品牌溢价提高
- **收窄预警**：市占率下滑、被迫降价竞争、核心技术被追赶、管理层频繁变动

#### 估值跟踪（老唐法动态更新）

> 唐朝：每年根据最新财报更新一次估值即可。不需要天天盯着股价。

- 每年更新一次"第三年预估净利润"
- 重新计算合理估值和买入/卖出价
- 对照当前股价，决定是否加仓/持有/减仓

#### 卖出哲学（三种情况才卖）

> 巴菲特：对于好公司，最佳持有周期是永远。卖出的理由不是"涨多了"。
> 唐朝：当前股价 ≥ 合理估值的150%时卖出；低于合理估值的70%时买入；中间不动。

**应该卖出的情形：**
1. **买入判断错了** — 当初对护城河、商业模式的判断被证明是错误的（最重要的卖出理由）
2. **基本面恶化** — 护城河明显收窄、ROIC 持续下滑、管理层出现诚信问题、三大前提不再满足
3. **严重高估** — 股价远超合理估值（唐朝标准：≥ 合理估值的150%），且发现更好的机会
4. **发现更好的机会** — 存在确定性更高、安全边际更大的替代标的（需真正比较，而非"草坪总是邻家的绿"）

**不应该卖出的情形：**
- 股价上涨（好公司涨了不是卖出理由）
- 市场整体下跌引发恐慌（好公司下跌是加仓机会）
- 短期业绩不达预期（需判断是否影响长期逻辑，一次性波动不改变投资论点）
- "专家"说要跌了（不做择时，不听预测）

- [ ] 3. 核心客户是谁？
- [ ] 4. 客户留存率/复购率如何？
- [ ] 5. 企业解决了客户什么核心麻烦/痛点？
- [ ] 6. 客户对公司产品/服务的依赖度高吗？
- [ ] 7. 如果公司明天消失，客户有多大的麻烦？

- [ ] 8. 竞争优势具体是什么？能否用一句话说清楚？
- [ ] 9. 能否提价而不流失客户？
- [ ] 10. 行业竞争主要靠什么手段？（价格？品质？渠道？关系？技术？）
- [ ] 11. 主要竞争对手是谁？他们的优势在哪里？
- [ ] 12. 竞争对手在做什么我们还没做到的事？

**财务健康与风险**
- [ ] 13. 负债是否过高？有息负债/EBITDA是否安全？
- [ ] 14. 会计政策是否保守？（折旧/摊销/减值/收入确认）
- [ ] 15. 营收是否依赖非经常性收入？
- [ ] 16. 公司是否有占用上下游款项的能力？（应付 > 应收 ?）
- [ ] 17. 主要经营风险有哪些？（列出Top 3）
- [ ] 18. 最坏的情况下，公司会亏多少钱？会不会倒闭？

**管理层**
- [ ] 19. 管理层是否可信任？言行一致吗？
- [ ] 20. 管理层薪酬是否合理？与业绩挂钩吗？
- [ ] 21. 管理层持股比例如何？有没有皮肤效应（skin in the game）？
- [ ] 22. 管理层的决策是否以股东利益为出发点？
- [ ] 23. 年报/业绩会上的信息是否清晰、一致、可追溯？

**成长与扩张**
- [ ] 24. 过去的增长来源于内生增长还是并购？
- [ ] 25. 如果是并购增长，并购是否成功？有没有买贵了？
- [ ] 26. 未来3-5年的增长点在哪里？
- [ ] 27. 增长空间有多大？天花板在哪？

**需求增长路径分析（唐朝法）**
- [ ] 28. 收入增长的三个路径哪个是主力？

  - 市场份额扩大（从对手那抢客户）
  - 产品/服务提价（定价权的体现）
- [ ] 29. 以上三个增长路径的可靠性和可持续性如何？
- [ ] 30. 如果三个路径同时失效，公司还能维持当前利润吗？

## 投资大师核心理念速查

> 以下是巴菲特、芒格、段永平、唐书房四位大师的核心理念精华，贯穿整个研究流程。

### 巴菲特
- 能力圈的大小不重要，清楚边界在哪里才重要
- 宁要模糊的正确，不要精确的错误
- 好公司的最佳持有周期是永远
- 管理层的首要能力是资本配置
- 伟大的生意本身就是最大的安全边际
- 每留存1美元利润，至少创造1美元市值增长

### 芒格
- Invert, always invert（反过来想，总是反过来想）
- 生活就是一连串机会成本的选择
- 鲁拉帕路萨效应：多因素同向叠加产生超额回报
- 从简单生意入手，培养分析能力
- 25种人类心理误判倾向是投资最大的敌人

### 段永平
- 先想清楚这是不是好生意、好公司，再谈价格
- 10年后这家公司还在吗？
- 企业文化是最深的护城河
- 说一套做一套的管理层，给再便宜也不买
- 投的是人，不是股票

### 唐书房
- 四大核心问题看懂一家企业
- 三大前提验证利润质量（真钱？可持续？不烧钱？）
- 老唐估值法：三年后净利润 × 合理PE → 折现到当前 → 7折买入
- 净利润是意见，现金流是事实
- 至少看10年财报，看完整的行业周期
- 聚焦资产负债表快速画像
- 高ROE是发现好企业的路标
- 区分真风险和假风险
- 好的管理层会在年报里主动讲"做得不好的地方"
- 保守的会计政策是管理层诚信的镜子
