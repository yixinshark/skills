## 零、能力圈自检

> 在开始研究之前，诚实回答以下问题（由AI提出，你自己回答）：

1. **你用过这家公司的产品/服务吗？** 身边谁在用？真实使用场景是怎样的？
2. **用大白话说：这家公司怎么赚钱？**（不许用"平台""生态""赋能"）：
3. **最大的竞争对手是谁？核心差别是什么？**：
4. **如果你是客户，什么情况下会换到对手那边？**：
5. **这个行业最近3年发生了什么大事？**：

**判断**：
- 能答4题以上 → 在能力圈内 ✅ 继续
- 能答2-3题 → 能力圈边缘 ⚠️ 先补课1-2周再回来
- 只能答0-1题 → 不在能力圈内 🛑 放弃

## 🎯 核心技能：必须对哪些财务数据变化保持高度敏感？

> **唐书房洞见**：财务报表不是一堆静止的数字，而是企业竞争力变化的动态记录仪。**趋势性变化**（连续3-5年同向移动）比单一年度的绝对值更重要，往往能提前1-2年预示护城河的扩大或收窄。以下是价值投资必须持续跟踪、保持高度敏感的关键数据。

### 一、盈利能力维度（必须连续看3-5年）

| 关键数据 | 趋势同向变化 | 含义解读 | 对护城河/竞争力的影响 |
|---------|-------------|---------|------------------------|
| **ROE（净资产收益率）** | 连续上升 | 盈利能力持续提升，竞争力增强 | ⬆️ 扩大 |
|  | 连续下降 | 盈利能力持续下滑，竞争力减弱 | ⬇️ 收窄 |
|  | 稳定在15%以上 | 具备持续赚取超额回报的能力 | ✅ 好生意 |
|  | 长期低于10% | 难以赚取满意回报，大概率不是好生意 | ❌ 排除 |
| **毛利率** | 连续上升 | 定价权提升/成本控制改善/产品结构升级（低毛利→高毛利） | ⬆️ 扩大 |
|  | 连续下降 | 竞争加剧被迫降价/成本上涨无法转嫁 | ⬇️ 收窄 |
|  | 显著高于同行且稳定 | 品牌/技术/网络效应护城河存在 | ✅ 强势 |
| **净利率** | 连续上升 | 经营杠杆释放/费用控制有效 | ⬆️ 改善 |
|  | 连续下降 | 费用膨胀/竞争挤压利润 | ⬇️ 恶化 |

|---------|-------------|---------|------|
| **经营现金流 / 净利润（净现比）** | 长期 > 1.0 | 利润是真金白银，盈利质量优秀 | ✅ 好 |

### 八大核心分析原则

1. **趋势比单年重要**：单一年度的变化可能是一次性因素，连续3年的同向趋势才是结构性变化。
2. **和竞争对手比**：你的毛利率升了1个百分点，但竞争对手升了3个百分点——你其实是相对跑输了。
3. **结合波特五力理解**：比例变化本质上是**五力格局的变化**——分成比例上升=供应商议价力增强，应收增速超过营收=客户议价力增强。
4. **提前1-2个季度反应**：竞争力变化会先在财务比例上体现，然后才反映在净利润和股价上。
5. **不理解变化就不投**：某个关键财务比例发生了你无法解释的剧烈变化 → 先排除，再研究。
6. **警惕突然的"美化"**：如果利润表突然变漂亮了，但现金流没跟上，很可能是会计调整。
7. **ROE要看结构**：靠提高杠杆撑起的ROE是最危险的信号；靠净利率提升驱动的ROE是最健康的。
8. **净现比是照妖镜**：长期净现比<0.8的公司，无论报表多漂亮，都要提高警惕。

### 盈利质量"三大前提"验证

> 唐朝：只有同时满足三大前提的企业，其报表净利润才能近似替代自由现金流，才有资格用老唐估值法（简化版DCF）。

**不适用老唐估值法的企业类型**：
- 利润含金量低或真实性存疑（如金融、保险等依赖模型假设的行业）
- 利润周期性波动大（如券商、航运）
- 需要持续大量资本投入才能增长（如地产、航空、电子制造）
- 具有梅特卡夫效应（用户规模指数增长）的互联网初创企业

**三大前提总评**：
- 三项全部 ✅ → 可用净利润近似替代自由现金流，进入老唐估值法
- 有 ⚠️ → 需调整估值模型，标注不确定性
- 有 ❌ → 不适用老唐估值法，需用更保守的DCF或直接放弃

- 如果买入这家公司，我必须卖掉持仓中哪家公司？：

- 结论：买入 ✅ / 因机会成本高而放弃 🛑
