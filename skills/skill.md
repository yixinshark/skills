# 价值投资研究技能 - SKILL.md

## 价值投资研究技能

### 核心原则

投资三要素（按优先级）：

1. **好生意** — 商业模式简单、护城河深、能长期存续
2. **好文化** — 管理层诚信、股东导向、资本配置能力强
3. **好价格** — 足够安全边际

> 段永平：先想清楚这是不是一门好生意、一家好公司，再谈价格。价格错了最多亏钱，方向错了则全军覆没。

---

## 研究流程

### 步骤0：能力圈自检（最优先，先于一切）

在开始任何研究之前，必须回答：

- **我是否真正理解这家公司的生意是怎么赚钱的？**
- 我能用一两句话向外行说清楚它的商业模式吗？
- 我对这个行业有没有第一手的认知（使用过产品、了解行业逻辑）？
- 如果不能满足以上条件 → **放弃，换下一个**，不在能力圈内的机会不是机会

> 巴菲特：我宁愿在能力圈内做简单的判断，也不愿在圈外做复杂的分析。能力圈的大小不重要，清楚边界在哪里才重要。

---

### 第一步：垃圾企业过滤（一票否决）

任何一条命中即判定为「不碰」，终止研究并告知用户原因：

- ROE连续3年 < 10%（非周期行业）
- 经营现金流/净利润连续3年 < 0.7（利润质量差）
- 资产负债率 > 70%（非金融企业）
- 商誉/净资产 > 30%（并购依赖）
- 管理层近1年大额净减持（⚠️ 需先核实减持原因：若为离婚、缴税、个人资产配置等与经营无关原因，可不否决；若无合理解释则否决）
- **重资产且利润微薄（"碎钞机"生意）**：资本开支常年远超折旧摊销，且ROIC低下，需频繁外部借款/融资才能维持生存的企业。
- 频繁再融资稀释股东
- 主业不清晰、频繁跨界
- 企业或管理层有违法行为、行政处罚、证监会处分记录
- 管理层诚信存疑（财务造假、虚假陈述、内幕交易等前科）

> **过滤结果输出标准**：
> - **✅ 通过初筛**：未触碰任何红线，进入深度研究。
> - **❌ 一票否决（不碰）**：当触碰红线时，需提供结构化的深度否决原因，包含：
>   1. **否决事件描述**：[具体时间节点] 发生了 [什么具体事实]。
>   2. **核心动机推测**：透过现象看本质，管理层这一动作背后的真实利益考量是什么？（例如：收益私有化、风险公众化、掩盖利润下滑等）。
>   3. **触碰的价投底线**：明确指出违背了哪一条大师原则（例如：违背段永平的“本分与诚信”最高红线、触碰巴菲特厌恶的“碎钞机模式”等）。

---

### 第二步：商业模式与行业竞争格局

#### 业务结构拆解（必须量化，从年报中提取）

- **各业务线收入构成**（表格形式，附毛利率）：明确每条产品线的营收、占比、毛利率，识别利润核心业务
- **收入地域结构**：国内 vs 海外占比；海外毛利率是否优于国内，海外布局方向
- **怎么赚钱的底层逻辑**：成本结构（原材料占比）、定价方式、规模效应的体现方式

#### 上下游结构（量化，从年报中提取）

**下游客户**：
- 已知核心客户名称（公开披露部分）
- 前五大客户销售额及合计占比（年报披露）
- 客户集中度判断：<25% 分散（低风险）；25-50% 中等；>50% 集中（高风险）
- 客户行业分布（食品/日化/医药等各自占比）

**上游供应商**：
- 主要原材料种类及价格敏感性（是否与大宗商品/油价挂钩）
- 前五大供应商采购额及合计占比（年报披露）
- 供应商集中度判断：<30% 分散；30-50% 中等；>50% 存在供应风险
- 公司是否在推进自建产业链以降低外采依赖

#### 行业竞争格局（必须分析）

- 行业整体规模、增速、天花板（市場空間有多大）
- **行业价值链结构**：上游→中游→下游各方的议价能力与利润分配
- **行业周期性**：是强周期/弱周期/非周期？利润率主要受什么变量驱动？最佳买入时机判断
- 竞争状态：完全竞争 / 寡头垄断 / 垄断；CR3/CR5 集中度
- 主要竞争对手列表：名称、营收规模、市占率、核心优势
- 目标公司在行业中的排名和市占率；5年增速 vs 竞争对手对比
- 行业进入壁垒高低（认证/资本/技术/品牌各维度）
- **政策与监管风险**：行业相关重大政策方向，是否存在技术升级/替代材料/环保合规等长期威胁
- 波特五力综合评分（附对目标公司具体影响说明）

#### 定价权评估（巴菲特通胀测试）

> 核心问题：**如果这家公司明天提价10%，客户会跑吗？**

- 历史上有无提价记录？提价后销量如何变化？
- 客户对价格的敏感度（刚需 vs 可选消费）
- 是否存在替代品压制定价空间？
- **结论**：定价权强 / 有限 / 无（附理由）

#### 护城河评估（每项1-5星 + 动态趋势）

| 维度 | 当前评分（1-5星） | 趋势（↑扩大/→稳定/↓收窄） |
|---|---|---|
| 客户转换成本 | | |
| 规模/成本优势 | | |
| 品牌/信誉 | | |
| 技术/专利壁垒 | | |
| 网络效应 | | |
| 特许经营权/牌照 | | |
| **企业文化（隐形护城河）** | | |

- **护城河总评：** 强 / 中等 / 弱（附理由）
- **商业模式的资本属性验证（印钞机 vs 碎钞机）**：业务增长是否需要成比例的庞大资本投入？维持现有利润的资本开支占多大？（好的生意是做大了就不需要怎么再投大钱的）。
- **动态判断：** 与3-5年前相比，护城河是在扩大还是收窄？竞争对手是否在蚕食份额？行业技术变革是否构成威胁？

#### 行业生命周期与演化趋势（时光机/参照系推演）

> 核心思想：**处于早中期的新兴市场/行业，通常会重演成熟市场/行业的历史路径。** （即孙正义的“时光机理论”）

- **当前所处阶段**：导入期 / 爆发期（量增为主） / 成熟期（存量博弈、集中度提升） / 衰退期（判断依据是什么？）
- **成熟市场参照系**：欧美、日本或中国一二线城市在类似发展阶段时，行业发生了什么关键变化？
- **演化推演**：未来3-5年，行业竞争的**核心驱动力**将从什么变成什么？（例如：从"渠道下沉"到"产品细分"，从"低价格战"到"品牌溢价"）
- **公司适配度研判**：目标公司当前的竞争优势，在进入下一个行业发展阶段时，是会失效还是依然适用？公司是否有能力完成战略跨越？

#### 10年后的公司图景（段永平灵魂问题）

> 段永平：我买公司之前一定要想清楚，10年后这家公司还在做同样的生意吗？

- 10年后这个行业还存在吗？需求是否会因技术/消费习惯变化而消失？
- 10年后这家公司的竞争地位是更强还是更弱？
- 当前的护城河能维持10年吗？
- **结论**：长期存续的确定性 高 / 中 / 低

#### 段永平三问

1. 这是不是一门好生意？（商业模式）
2. 这是不是一家好公司？（企业文化）
3. 现在是不是好价格？（估值）

### 第三步：企业文化评估

#### 本分与诚信（最深的护城河）

> 段永平：企业文化本身就是最深的护城河。如果文化不对，其他护城河迟早被填平。

- **本分与短期利润的取舍**：当“做对的事情”与“赚短期利润”冲突时，管理层如何选择？公司是否真正在为用户创造价值（而非单纯利用人性弱点）？
- 管理层言行一致性（对比历年致辞与实际经营）
- 管理层诚信 — 有无违法违规、行政处罚、证监会处分、诉讼纠纷
- 企业合规记录 — 有无环保处罚、税务问题、产品质量事故
- 信息披露质量（是否主动、透明、一致）

#### 股东导向

- 分红历史（是否持续、慷慨）
- 股权激励是否合理（行权条件是否真正高要求）
- 关联交易是否频繁

#### 管理层资本配置能力（巴菲特首要标准）

> 巴菲特：一家公司的命运，很大程度上取决于管理层如何分配资本。这是CEO最重要的能力，但商学院几乎不教。

- **历史收购记录**：做过哪些并购？是否创造了价值，还是溢价买入烂资产？
- **股份回购时机**：是否在低估时回购，高估时不买？
- **资本开支纪律**：高增长期是否克制，没有盲目扩张？
- **留存利润效率**：留下来的每1元利润，最终产生了多少市值？
- **资金去向透明度**：管理层对"钱花在哪里"是否解释清楚？
- **结论**：资本配置能力 优秀 / 一般 / 差（附例证）

---

### 第四步：财务分析

#### 核心指标（至少看5年趋势）

- 营收、净利润及增速
- **ROE**（杜邦分解：利润率 × 周转率 × 杠杆）
- **ROIC**（投入资本回报率，剔除杠杆影响，更真实反映生意本质）
  - ROIC = NOPAT / 投入资本（有息负债 + 净资产）
  - 若 ROIC 持续 > 15%，说明是真正的好生意
  - 同时看含商誉和剔除商誉两个口径
- **再投资能力**：再投资率 = 净增资本开支 / NOPAT；趋势是否递减？
- 毛利率、净利率
- 经营现金流/净利润
- 自由现金流 = 经营现金流 - 资本开支
- **资本密集度（Capex / 折旧与摊销）**：长期 < 1 是极佳的轻资产印钞机；远 > 1 则说明在流血维持运转。
- 资产负债率
- 分红率、股息率

#### 关注异常信号

- 营收增长但现金流不增长 → 应收账款问题
- 毛利率大幅波动 → 定价能力弱
- 存货周转变慢 → 产品滞销
- 有息负债突增 → 资金链风险
- ROIC 逐年下降但 ROE 稳定 → 依赖加杠杆维持表面回报

### 第五步：估值与买入价

#### 方法一：Owner Earnings（巴菲特法）

> Owner Earnings = 净利润 + 折旧摊销 - 维持性资本开支

#### 方法二：DCF简易模型

> 内在价值 = Σ(未来10年自由现金流折现) + 永续价值折现
>
> 折现率：10% / 永续增长率：不超过GDP增速（3%）

#### 方法三：历史估值区间

- 对比当前PE/PB与历史5年区间
- 股息率与历史对比

#### 📊 估值结论格式

- 内在价值估算：XX亿（每股XX元）
- 当前市值/股价：XX亿 / XX元
- 安全边际：XX%（**注意：伟大的生意本身就是最大的安全边际，不必死等绝对低估的"捡烟蒂"陷阱**）
- 合理买入价：≤ XX元
- 评级：【强烈推荐研究 / 值得关注 / 观望 / 不碰】

#### ⚖️ 机会成本测试（买入前最后的逼问）

> 芒格：生活就是一连串机会成本的选择。

- 如果买入这家公司，我必须卖掉持仓中哪家公司？
- 它的确定性和预期回报，真的比我手里最好的标的、或者无风险国债更优吗？
- 结论：买入 / 放弃（因为机会成本更高）

#### 💰 仓位建议

- 安全边际充足且确定性极高：可重仓（占组合15-20%）
- 安全边际 20-40%：中等仓位（占组合5-10%）
- 安全边际 < 20%：轻仓或观望
- 分批建仓策略：建议分3次买入，每次1/3仓位

> ⚠️ **违法违规特别说明**：如存在处罚记录但未达一票否决标准，须单独列出并评估影响。严重者直接排除。

### 第六步：芒格式反转检验（Pre-mortem）

> 芒格：Invert, always invert. 把问题反过来想，往往能看到正向思维看不到的风险。

在得出买入结论之前，强制做一次悲观推演：

- **投资论点破坏者**：什么情况下，当前的投资论点会彻底崩塌？（列举2-3个场景）
- **信息盲区**：有没有对手或市场已经知道、而我还不知道的关键信息？
- **5年亏损假设**：如果5年后这笔投资亏了50%，最可能的原因是什么？
- **我的偏见检查**：我是否因为喜欢这家公司/产品而高估了它？（可得性偏误）

#### 鲁拉帕路萨效应（Lollapalooza Effect）检查

- **多维共振**：这家公司是否在多层面上具备优势的同向叠加？（例如：极佳的商业模式 + 狂热的消费者行为 + 极度克制本分的管理层）。如果存在，通常预示着极为恐怖的长期回报。

> 以上问题能清晰回答，且风险可接受 → 继续；无法回答 → 暂停研究，补充信息

---

### 第七步：生成跟踪清单

为通过研究的企业生成季度/年度跟踪要点：

- 关键财务指标变化（重点盯 ROIC、自由现金流、毛利率）
- 经营层面需关注的事项
- 护城河是否在扩大或收窄的信号

#### 卖出哲学（三种情况才卖）

> 巴菲特：对于好公司，最佳持有周期是永远。卖出的理由不是"涨多了"。

**应该卖出的情形：**
1. **买入判断错了** — 当初对护城河、商业模式的判断被证明是错误的
2. **基本面恶化** — 护城河明显收窄、ROIC 持续下滑、管理层出现诚信问题
3. **发现更好的机会且当前明显高估** — 存在确定性更高、安全边际更大的替代标的

**不应该卖出的情形：**
- 股价上涨（好公司涨了不是卖出理由）
- 市场整体下跌引发恐慌
- 短期业绩不达预期（需判断是否影响长期逻辑）
