# 企业跟踪技能 - SKILL_TRACKING.md

## 企业跟踪技能

> **定位**：研究技能（skill_v2.md）的下游延续。初次深度研究完成后，用本技能对已纳入观察清单或持仓的企业进行持续跟踪。

## 核心原则

> 唐朝：每年根据最新财报更新一次估值即可。不需要天天盯着股价。
> 段永平：知道和做到之间有一条巨大的鸿沟。

1. **以研究报告为锚**：每次跟踪都基于初始研究报告中的投资论点，核心问题是"论点还成立吗？"
2. **只关注变化**：不重复初始研究的全部内容，聚焦"什么变了、为什么变了、影响多大"
3. **区分噪音与信号**：季度波动是噪音，趋势性变化是信号。不因短期数据改变长期判断
4. **纪律优先于情绪**：严格对照买入理由书/初始研究结论，不被股价涨跌左右

## AI辅助边界声明

AI能帮你做的：高效提取财报变化、交叉验证数字、标记异常信号、更新估值模型。

AI做不到的：判断管理层的话是否可信、感知行业微妙的竞争变化、替你做持有/卖出决策。

**最终决策权始终在你手中。**

## 跟踪触发场景

| 触发事件 | 跟踪深度 | 建议时效 |
|---|---|---|
| **年度财报发布** | 完整跟踪（全部步骤） | 年报发布后2周内 |
| **季度/半年度财报发布** | 快速跟踪（步骤1-4） | 财报发布后1周内 |
| **重大事件（并购/管理层变动/政策变化等）** | 事件专项分析（步骤5） | 事件发生后尽快 |
| **股价大幅波动（单日±10%或月度±30%）** | 真假风险判断（步骤6） | 波动发生时 |
| **年度估值更新** | 估值刷新（步骤7） | 年报数据确认后 |

#### 与市场一致预期对比（年报/半年报建议做）

> **为什么要加这一步？** 好公司+好业绩仍可能暴跌——因为市场定价的是"预期差"而非绝对值。一个+20%的利润增速，如果市场预期+30%，股价照跌。理解市场在期待什么，才能理解股价为什么这样反应。
> **注意**：这一步的目的不是跟着市场预期做决策（那是投机），而是理解短期价格波动的原因，以便判断是否出现了被"预期差"错杀的买入机会。

#### 预警触发标准

以下任一情况出现，必须在后续步骤中深入分析原因：

- **营收增速方向性逆转**（从正转负或反之）
- **净利润变动幅度 > 30%**（季报）或 > 20%（年报）
- **毛利率/净利率单期变动 > 3个百分点**
- **经营现金流/净利润 < 0.5**（单季度允许波动，连续2季需警惕）
- **应收账款增速 > 营收增速的1.5倍**
- **存货增速 > 营收增速的1.5倍**
- **资产负债率单期上升 > 5个百分点**
- **用户/客户参与度核心指标连续2个季度环比下降**（如用户时长、DAU、续约率等）
- **前瞻性Capex/费用指引大幅超出市场预期**（如Capex指引同比+50%以上）

**护城河财务诊断**：
- 7项全 ✅ → 护城河稳固，盈利能力持续性强
- 1-2项 ⚠️ → 护城河有压力，下期重点跟踪恶化的指标
- 任何一项 ❌ → 护城河可能在收窄，需深入分析原因（是一次性还是趋势性）
- 2项以上 ❌ → 护城河大概率在失效，启动卖出评估流程

### 步骤6：股价大幅波动应对（波动触发时使用）

> 巴菲特：股价波动不是风险，本金的永久性损失才是风险。
> 核心心法：不因股价涨跌改变判断，只因基本面变化改变判断。

#### 波动事实

- 波动幅度：
- 时间区间：
- 市场/行业是否同步波动：

#### 快速诊断

1. **是否有新的基本面信息？**（新财报、政策、行业事件）
   - 有 → 转步骤5做事件分析
   - 无 → 继续下一步

2. **投资论点是否因此变化？**
   - 否 → 市场情绪波动，忽略
   - 是 → 重新评估

3. **如果是下跌，当前价格是否进入/接近理想买点？**
   - 是 → 检查是否有余额可加仓
   - 否 → 继续等待

4. **如果是上涨，是否触发卖出条件？**（≥ 合理估值150% 或 PE > 50倍）
   - 是 → 考虑减仓
   - 否 → 继续持有

**结论**：忽略波动 / 考虑加仓 / 考虑减仓 / 需深入分析

## 跟踪纪律

### 频率要求

| 企业类型 | 最低跟踪频率 | 说明 |
|---|---|---|
| 重仓持有（>10%仓位） | 每季度 | 季报快速跟踪 + 年报完整跟踪 |
| 中等仓位（5-10%） | 每半年 | 半年报 + 年报 |
| 观察清单 | 每年 | 年报跟踪，有重大事件时临时跟踪 |

### 卖出决策流程

> 段永平：论点被证伪就卖出，不等回本。亏损不是认错理由，论点错了才是。

**触发卖出评估的条件**（满足任一即启动评估）：
1. 核心投资论点被证伪（护城河/商业模式判断失误）
2. 三大前提不再满足（利润不真、不可持续、或需要大量资本投入）
3. 管理层诚信出现根本性问题
4. 连续2次跟踪中论点状态为 ⚠️ 且无改善迹象
5. 股价触发卖出条件（≥ 合理估值150% 或 PE > 50倍）
6. 发现确定性更高、安全边际更大的替代标的

**不应触发卖出的情况**：
- 单季度业绩不达预期（看趋势，不看单点）
- 股价下跌（下跌不是风险，是机会——如果论点没变的话）
- 市场整体下跌带来的"陪跌"
- 分析师下调评级（他们的时间框架和你不同）

### 认知偏误自检清单（每次跟踪时快速过一遍）

- [ ] **禀赋效应**：我是否因为已经持有而不愿面对负面信息？
- [ ] **沉没成本**：我是否因为已经亏了而不愿认错？
- [ ] **确认偏误**：我是否只看到支持论点的证据？
- [ ] **锚定效应**：我是否被买入成本或历史高点锚定了？
- [ ] **过度自信**：我是否因为初始研究做得很详细就觉得不可能错？
